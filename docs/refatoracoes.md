## Refatoração 1 — Migração de SQLite para PostgreSQL

- **Motivo:** ADR 0001 — o SQLite é um arquivo numa máquina com um escritor por vez e não
  acompanha o crescimento que a Marta pede (R4); a revisão do ADR 0001 (22/10) exige ainda
  que os testes continuem sem conseguir apagar o banco real (ADR 0002, R6).
- **O que mudou:**
  - `src/db.js` — `node:sqlite` → `pg` (pool), `DATABASE_URL`; schema com
    `GENERATED BY DEFAULT AS IDENTITY`, `TIMESTAMPTZ` e `ADD COLUMN IF NOT EXISTS`; os
    **tipos que vazariam** do driver são consertados aqui (`count(*)` bigint e `numeric`
    viram número, `timestamptz` vira texto ISO); a sessão usa o fuso da máquina, como o
    `'localtime'` do SQLite; o banco de teste passa a ser `pratocheio_teste` e o
    `limparBanco()` recusa quando `current_database()` não é ele.
  - `src/repositorio.js` — `?` → `$1, $2…`; `datetime('now')` → `now()`;
    `strftime('%Y-%m', …, 'localtime')` → `to_char(…, 'YYYY-MM')`.
  - `.github/workflows/ci.yml` — `services: postgres` descomentado e `DATABASE_URL`.
  - `docker-compose.yml`, `.env.example`, `README.md` (`## Como rodar`).
  - `tests/` — **só preparação**: marcadores `$1`, o teste da migração de schema monta a
    tabela antiga com SQL do PostgreSQL e lê as colunas em `information_schema`, o teste do
    isolamento usa um banco descartável no lugar do arquivo, e o `vitest.config.js` cria o
    banco de teste e roda os arquivos um de cada vez (todos usam o mesmo banco).
- **O que NÃO mudou:** `src/doacoes.js` (fora do diff: `git diff main -- src/doacoes.js`
  vazio no PR da migração), `src/app.js`, as rotas, a interface e **nenhum `expect`**.
- **Evidência de que o comportamento se manteve:**
  - testes antes da mudança (SQLite, `main` em `0ce2a3b`): **19 passando** (5 arquivos) —
    CI: https://github.com/RogerKlock/g1126-template-prato-cheio/actions/runs/39832291225
  - testes depois da mudança (PostgreSQL 16): **19 passando** (5 arquivos)
  - link da execução do CI verde (PostgreSQL, PR #8): https://github.com/RogerKlock/g1126-template-prato-cheio/actions/runs/45857870069
